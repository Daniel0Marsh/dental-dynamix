# CodeBlock.io Website

This is the main company website for dentaldynamix.co.uk, built with Django and featuring a modern, responsive design.

### Active Domains:
- `dentaldynamix.co.uk` & `www.dentaldynamix.co.uk` → Port 8000 (Main site)


## Development

### Prerequisites
- Python 3.12+
- Poetry for dependency management
- Git

### Setup
1. Clone the repository
2. Install dependencies: `poetry install`
3. Run migrations: `poetry run python manage.py migrate`
4. Start development server: `poetry run python manage.py runserver`
